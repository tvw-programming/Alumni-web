## Description

Act as a front-end developer and UI/UX expert. Update the Admin alumni route
table (`apps/react-web` → `AlumniAdminGrid` / AG Grid via `AppDataGrid`) layout
and column widths.

### Layout

- The table must take 100% of the available container width (full width).

### Column width adjustments (baselines from current code)

Current column defs in `AlumniAdminGrid.tsx`:

| Column | Current sizing |
|--------|----------------|
| Name (`fullName`) | `flex: 2`, `minWidth: 170` |
| Year of passing | fixed `width: 150` |
| Course | `flex: 2`, `minWidth: 180` |
| Mobile | fixed `width: 160` |
| Email | `flex: 2`, `minWidth: 200` |
| Completion | fixed `width: 140` |
| Status | fixed `width: 130` |
| Pending media | fixed `width: 150` |

Required changes:

- **Course**: reduce by 20% → `flex: 1.6`, `minWidth: 144` (180 × 0.8).
- **Mobile**: increase by 20% → `width: 192` (160 × 1.2).

### Answers to prior ambiguity (required decisions)

**Q1 — Other columns after Course/Mobile change**  
Keep all non-Course / non-Mobile columns on their **current** sizing rules.
Do not invent new proportional shrink/grow for them. Fixed-`width` columns stay
fixed. Flex columns (Name, Email) keep their existing `flex` / `minWidth` and
AG Grid may redistribute leftover space among flex columns only — that is
expected.

**Q2 — Responsive behaviour on smaller screens**  
Use **horizontal scroll inside the grid** (AG Grid / AppDataGrid default). Do
**not** wrap columns into multi-line headers, and do **not** collapse into a
card/list layout for this ticket.

**Q3 — Baseline CSS / width values**  
Use the table above as the authoritative baseline. There are no separate CSS
percentage classes for Course/Mobile; widths are set on the AG Grid `ColDef`
objects in `AlumniAdminGrid.tsx`. Implement the 20% change against those values.

Ensure the layout remains cleanly aligned and visually balanced after these
adjustments. Long Course values may truncate with the grid’s default tooltip;
Mobile should display fully at the new width.

## Acceptance Criteria

- AC-1 The admin alumni table occupies 100% of its container width
- AC-2 Course column uses `flex: 1.6` and `minWidth: 144` (20% reduction from flex 2 / minWidth 180)
- AC-3 Mobile column uses `width: 192` (20% increase from width 160)
- AC-4 All other columns keep their previous ColDef width/flex values unchanged
- AC-5 On narrow viewports the grid scrolls horizontally; no card/list collapse and no column wrapping
- AC-6 Sorting, filtering, and editing behaviour of the grid are unchanged
- AC-7 Change is limited to `AlumniAdminGrid.tsx` column defs (no unrelated refactors)

## Out of scope

- Redesigning the admin page chrome or filters
- Changing row height, fonts, or theme tokens
- Server-side pagination / API changes
- Card or stacked mobile layouts
- Changing any column other than Course and Mobile widths
