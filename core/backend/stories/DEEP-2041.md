## Description

Signed-in users currently have no way to set a profile picture — the avatar
slot on the profile page falls back to initials for everyone. Support has
asked for this repeatedly, and it blocks the community-directory work planned
for next quarter.

A user should be able to upload an image from the profile page, see it
immediately, and replace or remove it later. The image is theirs alone: nobody
should be able to set an avatar on another person's account.

We already store generated files through `app/services/storage.py`, which
writes to a local directory in development and to object storage in
production. Reuse it rather than adding a second storage path.

## Acceptance Criteria

- AC-1 An authenticated user can upload a JPEG or PNG image as their own avatar
- AC-2 The uploaded image is validated: at most 2 MB, and actually a JPEG or PNG
- AC-3 A user cannot set or replace the avatar on another user's account
- AC-4 A user can remove their avatar, which returns the profile to initials
- AC-5 The avatar URL is included in the existing user profile response

## Out of scope

- Image cropping or resizing in the browser
- Animated formats (GIF, WebP animation)
- Avatar moderation or content scanning
- Gravatar or any third-party avatar fallback

## Notes

The 2 MB limit came from support: it is roughly the size of a phone photo
after the OS compresses it, and covers the reported cases without needing a
resize pipeline.

Retention when an avatar is replaced is not settled — see the open question on
whether the previous file should be deleted immediately or swept later.
